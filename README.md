# HuaRongDao 華容道

繁體中文 | [English](README.en.md)

網頁版華容道遊戲。線上試玩：https://huarong-dao.web.app

在瀏覽器玩的華容道。內建 106 個關卡，也可以自己設計關卡、檢查能不能解、存起來，或用分享碼給朋友。介面有繁體中文、简体中文、English 三種語言。

純前端靜態網站，不需要自己的伺服器或建置步驟；帳號與雲端同步用 Firebase（Authentication、Firestore）。

## 怎麼開

- 直接用瀏覽器打開 `index.html` 就能玩。
- 或在這個資料夾執行 `npm start`，再開 http://localhost:8080 。
- 部署到 Google Cloud：見 [DEPLOY.md](DEPLOY.md)，在 Cloud Shell 執行一行指令即可。
- 也可以放到任何靜態網站空間（GitHub Pages、Netlify、Cloudflare Pages…）。

## 資料存在哪裡

- 一律先存在瀏覽器的 localStorage：未登入時是 `huarongdao.v1`，登入後改用 `huarongdao.v1.u.<帳號 ID>`，登出時清掉。
- 部署在 Firebase Hosting 時可以登入帳號，資料存在 Firestore 的 `users/{uid}`（整份存成 JSON 字串），規則見 `firestore.rules`：每個人只能讀寫自己的那一份。
- 在 claude.ai 的預覽版裡，沿用 Claude 帳號，同步到使用者自己的空間（其他人看不到）。
- 多台裝置的合併規則（`js/store.js` 的 `merge`）：關卡取修改時間較新的、紀錄取成績較好的、設定取較晚改的；刪除關卡和「清除過關紀錄」會記下時間，其他裝置的舊資料不會再跑回來。合併結果跟先後順序無關，各台裝置最後一定一致。
- 進行中的局面每走一步都會存，但最多每 20 秒上傳一次（切換到其他分頁或 App 時立刻上傳），以節省雲端用量；其他變更大約 1.5 秒內上傳。
- 帳號功能的開關在 `js/cloud-config.js`：預設 `'auto'` 會在 Firebase Hosting 上自動讀取專案設定；改成 `null` 就不開帳號功能（關卡廣場也一起關掉）。

## 關卡廣場的資料

| Firestore 路徑 | 內容 | 誰可以寫 |
| --- | --- | --- |
| `levels/{id}` | 分享碼、名稱、說明、作者、大小、最少步數、讚數、過關人數、檢舉次數 | 作者建立、改名稱和說明、刪除；計數欄位只能跟著下面的文件一起 +1／-1 |
| `levels/{id}/likes/{uid}` | 按讚 | 自己（作者取消發佈時會一起刪） |
| `levels/{id}/records/{uid}` | 公開名稱、步數、用時、提示次數 | 自己，只能換成更好的成績，步數不能少於最少步數 |
| `reports/{id}_{uid}` | 檢舉原因 | 自己，每一關一次；只有管理者在主控台看得到 |

- `id` 是盤面（左右翻轉取較小的那個）的 64 位元雜湊，所以同一個盤面只能發佈一次。
- 規則見 `firestore.rules`；最少步數由發佈的人的瀏覽器算好送上來，玩的人打開時會再算一次。
- 關卡廣場只在部署到 Firebase 時出現；claude.ai 預覽版和只放靜態檔的主機不會顯示。

## 排行榜的資料

| Firestore 路徑 | 內容 | 規則檢查 |
| --- | --- | --- |
| `players/{uid}` | 公開名稱、星星數、過關數、`score = 星星 × 1000 + 過關數` | 星星和過關數只能跟著某一關的紀錄一起變，差距要對得上 |
| `boards/{關卡}/records/{uid}` | 步數、用時、走法（每步 3 個字） | 只收內建關卡；步數不少於最少步數；每步至少 0.2 秒；只能換成更好的成績 |

- 內建關卡的最少步數寫在 `firestore.rules` 裡，改了 `js/levels.js` 之後要執行 `node tools/sync-rules.js`（測試會檢查有沒有同步）。
- 規則沒辦法驗證走法本身，所以顯示各關排行時，瀏覽器會照走法重播一次，走不到出口的紀錄不顯示。總排行只看數字，沒辦法逐一驗證。
- 依步數、用時排序要用 `firestore.indexes.json` 的複合索引，部署腳本會一起上傳。

## 多語系

- 程式裡的文字一律寫繁體中文原文並包在 `t()` 裡，例如 `t('最少 {n} 步', { n: 81 })`；`js/i18n.js` 依目前語言查對照表。
- `js/i18n/zh-Hans.js`：简体中文，由 `npm run i18n:hans` 用 [OpenCC](https://github.com/nk2028/opencc-js) 從原文自動產生（含詞彙轉換，例如「設定」→「设置」），不要手改。
- `js/i18n/en.js`：英文翻譯。英文需要分單複數時寫成 `{ "one": "…", "other": "…" }`。
- 新增或修改文字之後：先執行 `npm run i18n:hans`，再把 `npm run i18n` 列出缺少的英文補進 `js/i18n/en.js`。測試會檢查兩種語言都沒有漏翻、參數也對得上。
- 內建關卡的名稱、說明和預設的武將名字存的是原文，顯示時才翻譯，所以存檔、分享碼、雲端資料都不受語言影響。

## 內建關卡的來源

- 經典、海外和部分入門／進階／挑戰關卡的盤面，取自 [發芽網](http://fayaa.com/youxi/hrd/) 的華容道佈局整理（經由 [SimonHung/Klotski](https://github.com/SimonHung/Klotski) 收錄的資料），並和 [jeantimex/hua-rong-dao-html](https://github.com/jeantimex/hua-rong-dao-html)、[conwnet/huarongdao](https://github.com/conwnet/huarongdao)、[GNOME Klotski](https://github.com/GNOME/gnome-klotski) 交叉比對。來源附的最少步數和本專案解題器算出的完全一致。
- 名稱改為繁體中文；英文佈局的中文名稱（雛菊、紫羅蘭、罌粟、三色堇、雪花蓮、錦旗難題）是翻譯的；說明文字是自己寫的。
- 入門 5 關、進階 3 關、挑戰 2 關（崇山峻嶺、十面埋伏）和變化 4 關是用解題器挑出的原創關卡。

## 關卡 JSON 格式

```json
{
  "app": "huarongdao",
  "version": 1,
  "levels": [
    {
      "name": "橫刀立馬",
      "description": "最經典的開局",
      "difficulty": 4,
      "board": { "cols": 4, "rows": 5 },
      "exit": { "side": "bottom", "at": 1 },
      "goal": { "x": 1, "y": 3 },
      "pieces": [
        { "type": "king", "x": 1, "y": 0, "label": "曹操" },
        { "type": "tall", "x": 0, "y": 0, "label": "張飛" },
        { "type": "wide", "x": 1, "y": 2, "label": "關羽" },
        { "type": "soldier", "x": 1, "y": 3, "label": "兵" }
      ],
      "minMoves": 81
    }
  ]
}
```

棋子種類：`king` 曹操 2×2、`tall` 直將 1×2、`wide` 橫將 2×1、`soldier` 小兵 1×1。座標從左上角 (0, 0) 起算。

- `board`：3–6 欄（cols）、4–7 列（rows）。
- `exit`：出口在哪一邊（`bottom`／`top`／`left`／`right`）與第一格的位置 `at`（上下邊是第幾欄、左右邊是第幾列，從 0 起算），寬兩格。
- `goal`：曹操要抵達的左上角位置，由 `exit` 推算；舊資料只有 `goal` 時會自動推回出口。

## 分享碼格式

```
HRD1-ABBCABBCDEEFDGHFI..J-eyJuIjoi5qmr5YiA56uL6aasIn0-5vtv
     └─ 盤面 20 格 ─────┘ └─ 名稱等資料 ─────────┘ └檢查碼
HRD2-55R1-AAB..AABC.DDEFGHHIFGJJIKK-eyJ…-zn0q
     └┬─┘ └─ 盤面 欄×列 格 ──────┘
      5 欄 5 列、出口在右側（R）、從第 2 列開始（1）
```

標準 4 × 5、出口在下方中央的關卡用 HRD1（較短），其他用 HRD2；兩種都能貼上匯入。

- 盤面：由左上到右下，每格一個字元，同一顆棋子同一個字母，`.` 是空格。
- 名稱等資料：`{n 名稱, d 難度, l 和預設不同的棋子文字}` 的 JSON，UTF-8 後轉 Base64URL。說明文字不放進來，讓分享碼保持在 60 字元左右。
- 檢查碼：前兩段的雜湊，抄錯或被截斷時會提示。
- 分享連結 = 網站網址 + `#/s/` + 分享碼。不需要伺服器，網站部署在哪裡都能用。
- 挑戰連結 = 分享連結 + `/r<步數>t<秒數>`，例如 `…/r85t222`。成績寫在網址裡、沒有防偽，只適合朋友間互相挑戰。
- 在 claude.ai 預覽版或直接開檔案時沒有可分享的網址，只會顯示分享碼。
